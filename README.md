**论文读完了，却还是说不清它到底做了什么？**

术语看懂了，方法没走通；表格看完了，还是说不清结果为什么会这样；作者给出了响亮的新名字，却看不出真正新增了什么。

祛魅阅读不照着作者的包装复述论文。它先去掉模块名和宣传语，用白话讲清这项工作到底做了什么；再把作者声称的每一项贡献和最接近的前人工作逐一对比，分清哪些是借来的、哪些是真正新增的；最后解释结果为什么会这样、值不值得信。评审意见、版本变化、官方代码和独立复现只用来校准成熟度和可用性，不代替对“新在哪里”的判断。

![祛魅阅读地图：快速导读与完整精读](assets/clear-eyed-reading-map-v6.png)

## 输出长什么样

两种读法都按同样六个读者问题组织，标题跟随你的语言：

1. **一句话**：去掉作者命名后它做了什么、最重要的新东西、总体判断，以及依据的版本和查过哪些材料。
2. **它要解决什么问题**：难在哪里，以前的人怎么做。
3. **它怎么做的**：一张纯文本框线图，加一个带具体数值的例子逐步走通；公式放在用到它的那一步，代入例子的数字。
4. **真正新在哪里**：一张表列出每项声称贡献——已有什么、本文改了什么、去掉会损失什么。
5. **结果为什么是这样、可信吗**：撑起结论的证据、最有力的另一种解释，以及评审、新版本、代码或复现中会改变判断的发现。
6. **值不值得读、怎么用**。

框线图放在代码块里，在终端、Claude Code 和普通聊天界面里显示一致；框内只用短英文标签以保证对齐，说明写在右侧注释里，`★` 表示本文新增，`○` 表示复用或外部部件：

```text
  question
      │
      ▼
┌───────────┐
│ retriever │  ← ○ 现成的 BM25 检索，没改
└─────┬─────┘
      │ top-20 passages
      ▼
┌───────────┐
│ reranker  │  ← ★ 本文新增：小模型给每段重新打分
└─────┬─────┘
      │ top-3 passages
      ▼
┌───────────┐
│ LLM       │  ← ○ 现成的语言模型写出答案
└───────────┘
```

## 选择阅读深度

| | ⚡ `clear-eyed-reading` | 🔬 `clear-eyed-deep-reading` |
| --- | --- | --- |
| **适合** | 快速读懂，决定要不要继续投入 | 彻底掌握，准备复述、复用或质疑 |
| **查多深** | 覆盖全部重要声称贡献；只深挖会改变总体判断的主张、近邻工作和一次低成本的评审/版本/代码检查 | 全文、附录、关键原图、公式、实现细节，并系统核对评审、版本、作者材料、代码、复现和引用语境 |
| **输出** | 六节都压缩：一张框线图、一个短例子，细节只留结论和原因；默认不打分 | 六节逐一展开：每个模块用同一例子走通、公式带数字、原图导读、实验与消融、五维评分 |
| **读完能做什么** | 决定是否继续读，或改用完整精读 | 复述、画出、复用并质疑方法 |

两种读法回答同样的问题、用同样的标准，只是查证成本和展开程度不同。快速导读在需要穷尽展开时会建议改用 `$clear-eyed-deep-reading`。

## 判断依据

- 🔍 **去掉名字再理解**：把术语和模块还原成“进来什么、做了什么、出去什么、为什么需要”，并说清能力到底来自本文，还是来自数据、预训练模型、已有方法、人工选择或后处理。
- 🌍 **和最接近的前人工作比**：通过检索、参考文献、后续引用、旧术语和相邻领域找近邻，读原文对比；不把 Related Work、引用量、下载量或摘要相似度当答案。
- 🎯 **解释结果从哪来**：比较方法本身与数据、规模、基线选择、评测方式、实现细节等其他可能原因。
- 📎 **正文之外只做校准**：评审、版本、代码、复现和引用语境用来判断成熟度、可复现性和使用注意；查不到就说没查到，不用缺失反推结论。

祛魅不是找茬，也不因简单、工程化或早期就自动贬低；被低估的结构性贡献同样会被讲出来。关键比较没做完时，不猜测新意和意义评分；没有 subagent 时按顺序完成同样的查证。

## 直接使用

两个 Skill 都只在用户显式调用时运行。

```text
快速导读：使用 $clear-eyed-reading 核验并讲清这篇文章的所有重要创新与贡献：<链接或附件>
完整精读：使用 $clear-eyed-deep-reading 把这篇文章的机制、关键公式、图表、实验和真正的新东西逐步讲懂：<链接或附件>
```

## 安装与兼容性

两个目录都是自包含安装产物，可放入**任意** agent harness 的 Skills 搜索路径。核心指令不绑定 Codex、Cursor 或其他平台，也不绑定特定模型、MCP、CLI、平台 API 或输出语言。普通用户不需要 Python。早期版本用户可移除旧的 `clear-eyed-paper-reading` 和 `clear-eyed-paper-deep-reading` 目录，避免入口名混淆。

手动安装（任意 harness）：

```sh
cp -R skills/clear-eyed-reading skills/clear-eyed-deep-reading <your-harness-skills-dir>/
```

可选：`python3 scripts/install_skills.py` 会复制到本机已存在的个人 Skills 目录；用 `--dest <skills-dir>` 指定任意未知平台。`--list` 预览目标，`--dry-run` 只打印不写入。

🛡️ 文章内容只被视为研究材料；未经许可，Skill 不执行文中代码，也不上传未公开材料。
