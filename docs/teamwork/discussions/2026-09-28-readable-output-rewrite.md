# 祛魅阅读输出重写：易懂结构 + 终端框线图

## 当前结论

- **目标不变**：去掉作者包装后讲清实际做了什么、能力从哪来、真正新在哪、结果为什么这样。
- **输出改为固定六个读者问题**（一句话 / 解决什么问题 / 怎么做的 / 真正新在哪 / 结果为什么这样、可信吗 / 值不值得读），标题用用户语言；非论文材料可合并或改名，顺序不变。取代 2026-08 "标题跟随材料、不给固定结构"的旧决定，原因见下方用户反馈"结构不清"。
- **禁止技能内部标签进入输出**（四个判断、能力来源、真实增量、伴生证据、贡献图等），领域术语首次出现用短句解释。
- **机制必须用带具体数值的例子逐步走通**，公式放在使用它的步骤并代入数字。
- **图示唯一路径：`text` 代码块内的 Unicode 框线图**，不再用 Mermaid；框内只放短 ASCII 标签以保证中日韩文本不破坏对齐，说明写在框右侧 `← 注释`，`★` 标本文新增、`○` 标复用或外部部件。原图只按编号导读，界面能显示图片时才嵌入。
- 调研规则保留实质（版本、原文、多路径找近邻、其他解释、六类正文外材料只做校准、按风险停止、评分门槛、安全），删去指纹、证据卡、四轨等流程术语。

实现位置：[`skill-src/core.md`](../../../skill-src/core.md)、[`skill-src/output/chat.md`](../../../skill-src/output/chat.md)、[`skill-src/depth/`](../../../skill-src/depth)；新增回归用例 `reader-sections-plain-vocabulary`、`terminal-box-diagram`、`running-example-concrete-values`。
